schema

Schema (datos estructurados) ayuda a los buscadores a entender mejor el contenido de tu web y a mostrar información extra en los resultados.

{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "Tu Web",
  "url": "https://tuweb.es"
}
Schema.org
robots.txt

robots.txt indica a los buscadores qué zonas de la web se pueden rastrear y dónde está el mapa de páginas.

User-agent: *
Allow: /

Sitemap: https://tuweb.es/sitemap.xml
robots.txt
canonical

Las etiquetas canonical evitan el contenido duplicado al indicar a los buscadores cuál es la versión principal de cada página.

<link rel="canonical"
  href="https://tuweb.es/" />
Canonical
meta tags

Las meta tags definen el título y la descripción que aparecen en Google: el primer contacto de tu público con tu web.

<title>Tu Web</title>
<meta name="description"
  content="Lo que haces." />
meta tags
sitemap

sitemap.xml enumera todas las páginas de la web y facilita el rastreo y la indexación a los buscadores.

<urlset>
  <url>
    <loc>https://tuweb.es/</loc>
  </url>
</urlset>
sitemap.xml
index

El archivo index.html es la página principal de tu web. Estructura el contenido e inicia tu presencia en internet.

<!DOCTYPE html>
<html lang="es">
  <head>
    <title>Tu Web</title>
  </head>
  <body>...</body>
</html>

Si tus clientes solo te encuentran por recomendación o por anuncios, y tu web funciona casi como un portfolio porque el tráfico orgánico prácticamente no existe, el problema probablemente no es el diseño, sobre todo si tu web ya es bonita y llamativa. Toda web que no se encuentra en las búsquedas orgánicas tiene problemas en una de estas 4 capas, o en todas:

Encontrabilidad

La capacidad de la web de ser descubierta, rastreada e indexada por Google.

Relevancia

¿La página responde exactamente a lo que se está buscando?

Confianza

¿Los buscadores y la IA consideran tu web una fuente con autoridad y legítima?

Acción

¿El visitante entiende qué hacer cuando encuentra tu web?

La publicidad lleva gente a tu web. Pero que te encuentren es mejor, igual que tú nos has encontrado.

Cuando tu web se muestra

Instagram, recomendaciones y anuncios que interrumpen a alguien y le piden atención. Funcionan, pero dependen de que sigas pagando o publicando, y de que esa persona siga interesada en lo que ofreces justo en ese momento.

Que te encuentren es mucho mejor

La estructura de búsqueda hace que tu negocio aparezca justo cuando alguien ya ha decidido buscar lo que ofreces.

«Es más fácil vender a quien ya está buscando lo que vendes que convencer a alguien de que compre.»

«Mi web es bonita y moderna, y mi diseñador ya puso todas las palabras clave.»

Tener palabras clave en la web no es lo mismo que tener una web construida sobre una estrategia de búsqueda. Una web puede ser bonita y seguir dependiendo por completo de Instagram, las recomendaciones y los anuncios para que la gente llegue a ella.

La verdadera pregunta va mucho más allá:

¿Qué búsquedas captan realmente esas palabras clave?
¿A qué intención de búsqueda responde cada página?
¿Cómo está indexando Google esas páginas hoy?
